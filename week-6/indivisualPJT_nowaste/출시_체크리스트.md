## A. 쿠팡파트너스 (수익화) — 지금 바로 가능
> 코드·제휴 고지 UI는 이미 완료. 남은 건 **신청 → 승인 → 링크 한 줄**. 상세: [제휴신청_가이드.md](제휴신청_가이드.md) §1

- [ ] 🧑 **가입** — partners.coupang.com, 쿠팡 계정으로 로그인
- [ ] 🧑 **정산정보** 입력 (계좌·주민번호/사업자 — 세금 신고용)
- [ ] 🧑 **채널 등록** ← 핵심. 웹사이트 채널로 **`https://nowaste-app-seven.vercel.app`** 등록
- [ ] 🧑 **약관 동의 → 신청 → 심사** (며칠 내, 비교적 관대. 앱이 배포돼 '실제 접근성' 충족)
- [ ] 🧑 **승인 후** — 파트너스 대시보드에서 검색/상품 링크 생성 방식 + **트래킹 ID(subId)** 확인
- [ ] 🤖 **적용** — 알려주시면 Vercel 환경변수 `MARKET_URL_COUPANG=…{q}…&subId=…` 넣고 재배포 (코드 변경 0)
- [ ] ⏳ 모바일 출시 후 파트너스에 **"앱" 채널 추가**(정책상 깔끔, 계정·트래킹은 그대로 유지)

⚠️ 정책 주의: **자기 클릭 금지**, 승인 후 **일정 기간 내 최소 실적** 조건 있을 수 있음, 제휴 고지 문구 필수(→ 앱에 이미 있음).

1. **지인 10~20명 테스트** — 실제로 계속 쓰는가? (여기서 온보딩·버그 잡기) ← 스토어 심사보다 값진 관문
2. **쿠팡파트너스 신청**(A) — 지금 웹 URL로. 승인은 평생 계정 것이라 미리 받아두면 이득
3. **앱스토어 제출**(B) — 위가 어느 정도 되면
4. 출시 후 **`/admin` 대시보드로 추이 관찰** → 개선

> 초기 기대치는 냉정하게: 개인 앱 대부분 MAU 1,000도 어렵다. 목표는 "우리집 절감 + 지인이 계속 씀 + 파트너스 첫 수익". 매각은 그 결과로 따라오는 것(로또). — STRATEGY.md
