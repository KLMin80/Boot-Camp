# 🔗 제휴(수익화) 신청 가이드 — 남김없이

앱 코드·고지 UI는 **이미 준비 완료**예요. 남은 건 **당신이 제휴에 신청**하고, 승인되면 **`.env`에 링크 한 줄**만 넣는 것.

---

## 지금 상태 (코드 쪽은 끝)

- ✅ 멀티마켓 링크는 `server.js`의 `MARKETS` 한 곳에서 생성 (쿠팡·컬리·이마트몰·네이버)
- ✅ **`.env`로 교체 가능** — 승인 후 `MARKET_URL_<KEY>` 템플릿만 넣으면 코드 수정·재빌드 없이 딥링크로 바뀜 (검색어 자리 = `{q}`)
- ✅ **제휴 고지 UI 탑재** — 구매 시트에 ‘제휴’ 배지 + "구매 시 수수료를 받을 수 있고, 가격은 동일" 문구 (표시·광고의 공정화에 관한 법률상 필수)

## 1) 쿠팡파트너스 — **가장 현실적인 수익원 (개인 가능)**

> [partners.coupang.com](https://partners.coupang.com) · 화면 문구는 조금씩 바뀔 수 있으니 안내 따라가되, 흐름은 이래요.

**① 가입/로그인** — 쿠팡 회원이면 그 계정, 아니면 가입 → **휴대폰 본인인증**(실명·본인 명의, 미성년자 불가)
**② 기본 정보** — 이름·연락처
**③ 채널(수익 낼 곳) 등록** ← 핵심
- 유형: "웹사이트/앱"
- URL: `https://nowaste-app-seven.vercel.app`
- 설명: "냉장고 관리·장보기 앱, 부족 재료를 여러 마켓 비교로 주문"
**④ 정산 정보** — 정산받을 **계좌**, (실제 수익 발생 시)세금 정보(처음엔 기본만)
**⑤ 약관 동의 → 신청 → 심사** — 비교적 관대·빠름(며칠 내). 채널에 **실제 콘텐츠/접근성**이 있어야 함 → 지금 앱 배포돼 있으니 충족
**⑥ 승인 후 · 링크 생성** — 대시보드에서 **검색/상품/카테고리 링크** 생성 → 트래킹 ID(subId) 붙은 URL을 받음

**승인 후 적용 (코드 안 건드림):**
1. 위 검색 링크를 받아서 → 검색어 자리에 `{q}`만 남기고
2. Vercel 환경변수(또는 `.env`)에 추가:
   ```
   MARKET_URL_COUPANG=https://link.coupang.com/re/…?q={q}&subId=nowaste
   ```
3. 재배포 → 끝. 앱의 **쿠팡 버튼 + 밀키트 링크**가 전부 제휴 링크로 바뀜. → **링크만 주시면 제가 넣고 재배포해요.**

> ⚠️ 정책: 승인 후 **일정 기간 내 최소 판매 실적** 조건이 있을 수 있음(사이트 확인), **카톡 등 일부 공유 제한**, **자기 클릭 금지**, **제휴 고지 문구 필수**(→ 앱에 이미 있음).

### 🔑 웹으로 승인 → 나중에 모바일앱, 그대로 유지되나? → **네, 유지돼요.**
- **파트너스 계정·트래킹 ID는 "당신"에게 부여**돼요(채널에 종속 X). 채널(웹/앱)은 계정 아래 여러 개 추가 가능 → **재승인·새 계정 불필요.**
- **우리 앱 구조가 특히 유리:** 모바일앱은 Capacitor로 **배포된 웹앱(같은 URL)을 그대로 로드**함 → 화면·쿠팡 링크(트래킹 ID)가 웹과 **100% 동일** → **모바일에서도 그 수익 그대로.**
- **딱 하나 권장:** 모바일 출시 시 파트너스에 **"앱" 채널을 하나 추가 등록**(정책상 깔끔). 계정·트래킹·기존 링크는 전부 유지.
- **결론: 지금 웹으로 승인받아 두면 그 승인이 평생 계정 것.** 모바일은 채널만 추가. → **지금 신청해두는 게 이득.**

## 2) 쿠팡 외 몰 확장 — **어필리에이트 네트워크 (CPS)**

솔직히: **네이버쇼핑 자체는 개인이 쇼핑 검색 링크로 커미션 받는 정식 경로가 없다시피** 해요.
- 네이버 애드포스트 = 블로그·미디어 광고용(앱 링크와 성격 다름), 쇼핑파트너센터 = 판매자용.
- 참고로 지금 앱의 `NAVER_CLIENT_ID/SECRET`은 **검색 API(참고 최저가)**용이지 수익 채널이 아니에요.

**대신 쿠팡 외 몰(11번가·GS샵 등)까지 제휴를 넓히려면 → CPS 어필리에이트 네트워크에 개인 가입:**
- **링크프라이스(linkprice.com)**, 애드픽, 텐핑 등 — 개인도 매체(사이트/앱) 등록 후, 광고주(몰)별로 제휴 신청 → 승인되면 딥링크 생성.
- 신청 흐름: 가입 → 매체(앱 URL) 등록 → 원하는 몰 제휴 신청 → 승인 후 링크 생성 → `.env`에 `MARKET_URL_<KEY>`로 교체.
- ⚠️ 네이버쇼핑·컬리·이마트가 그 네트워크에 있는지는 **가입해서 광고주 목록을 직접 확인**해야 해요(수시로 바뀜).

**그래서 지금 권장:** 쿠팡파트너스 먼저(확실). 네이버·컬리·이마트는 **‘비교용’으로 유지**하다가, CPS 네트워크에서 해당 몰 제휴가 열리면 그때 `.env`로 붙이기.

## 3) 컬리 큐레이터 · 네이버 쇼핑 커넥트 (2026 확인)

### 🥬 컬리 큐레이터 — ⚠️ SNS 인플루언서 프로그램 (앱과는 결이 다름)
> 큐레이터가 컬리 상품 링크를 **자기 SNS에 공유** → 팔로워가 24시간 내 구매 시 리워드. 수수료 **최대 15%**.

**신청 위치 (마이컬리에 안 보이는 이유):**
- 공식 페이지: **[lounge.kurly.com/curator-program/welcome](https://lounge.kurly.com/curator-program/welcome)** ← 여기로 바로.
- 신청은 주로 **컬리 앱(모바일) → 마이컬리**에서 SNS 채널 URL 등록. **웹 마이컬리엔 없을 수 있음**(앱 위주).

**가입 조건 (중요):** **SNS 채널 팔로워 수** 기준 —
- **1star**: 유튜브/인스타 **팔로워 1,000명 이상**
- **2star**: **3만명 이상**

**⚠️ 우리 앱과의 궁합 — 솔직히 안 맞음:**
- 큐레이터는 **"내가 내 SNS에 컬리 상품을 홍보"**하는 인플루언서 모델. **앱에 링크를 임베드**하는 일반 어필리에이트(쿠팡파트너스)와 성격이 다름.
- 앱 URL은 '채널(팔로워)'이 아니라 **큐레이터 채널로 부적합**. 인스타(@klmin9)로 신청하려면 **팔로워 1,000명+** 필요.
- 즉 **앱의 컬리 버튼 수익화 수단으로는 부적합**. (개인 인스타로 컬리 상품 홍보를 하고 싶다면 별개로 유용)

**결론:** 앱 수익화는 **쿠팡파트너스 중심**을 유지하고, **컬리는 비교용(트래킹X 검색)**으로 둔다. 앱용 컬리 제휴가 필요하면 **CPS 네트워크(링크프라이스 등)에 컬리 광고주가 있는지** 확인하는 게 정공법(→ 위 2)번).

### 🔎 네이버 쇼핑 커넥트 — 가입은 쉬우나 앱 궁합 X (당장 보류 권장)
- **가입:** 네이버 계정 크리에이터면 **승인심사 없이 약관동의 즉시**. 수수료 판매자 자율(최대 50%).
- ⚠️ **문제:** 링크가 특정 **스마트스토어 '상품' 단위** → 우리 앱의 '재료 검색' 버튼엔 부적합(재료마다 특정 상품 지정 불가).
- **권고:** 네이버는 **비교용(트래킹X 검색)으로 유지**. 앱에 '이 재료엔 이 상품 추천' 같은 **큐레이션 기능**이 생기면 그때 연동.

## 현실적인 결론

- **당장 수익화 = 쿠팡파트너스 하나에 집중.** 신청→승인→`.env` 한 줄. (밀키트도 이걸로 커버됨)
- 쿠팡 외는 **CPS 네트워크(링크프라이스 등)**로 열리는 것만 붙이기.
- 손익분기(COST.md): 가구당 월 운영비 ~₩233 → **쿠팡 제휴로 월 1만 원대만 전환돼도 상쇄.**
